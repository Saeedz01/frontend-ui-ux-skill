# Frontend UI/UX Design and Development Standards

A reusable frontend UI/UX skill for building consistent, accessible, responsive, performant, and user-friendly web interfaces.

The skill provides practical standards for visual hierarchy, spacing, typography, color systems, reusable components, responsive design, accessibility, forms, validation, loading states, search, user control, performance, and frontend code organization.

## What it covers

The skill defines standards for:

* Visual hierarchy and layout consistency
* Global content containers
* Spacing and 8-point spacing principles
* Centralized color and typography systems
* Consistent component design
* Responsive and mobile-first layouts
* Accessibility and keyboard navigation
* Forms and validation
* Loading, empty, error, and offline states
* Search suggestions and keyboard-friendly search
* Destructive actions and user control
* Breadcrumb navigation
* Performance considerations
* Printable A4 PDFs
* Component reuse and code organization
* Scope-aware frontend validation
* Preserving meaningful code comments

## Usage

Copy `SKILL.md` into the skills/instructions location supported by your AI coding tool or reference the file when asking an AI coding agent to perform frontend work.

The instructions are designed to be reusable across frontend projects and can be adapted to the project's existing design system and technical conventions.

## Core principle

Build interfaces that are consistent, accessible, familiar, efficient, and easy to understand while keeping the implementation maintainable and production-ready.
